# InterviewAce

AI-powered virtual interview preparation, skill assessment, resume building, company preparation, SWOC analytics, and an Ace AI placement agent for HSC-passed and undergraduate students.

## Quick start

1. Copy `.env.example` to `.env.local` and set a PostgreSQL `DATABASE_URL`.
2. Run `npm install`.
3. Run `npx drizzle-kit push`.
4. Run `npm run dev`.
5. Open `http://localhost:3000` and verify `/api/health`.

See `DEPLOYMENT.md` for persistent Vercel + Neon and Railway deployment instructions. Do not use a temporary E2B preview URL as a production backend.
